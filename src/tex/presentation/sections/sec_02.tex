            \justifying 
            \textbf{Details}
            \vspace{1em}

            \begin{overlayarea}{\textwidth}{4.5cm}
                \only<1>{
                    To work with gradient descent, the covariance matrix $\Sigma$ must be differentiable and remain positive semi-definite (eigenvalues $\ge 0$) to be geometrically valid.\\
                    \vspace{1em}
                    Running a loop during backpropagation to find valid values is computationally too costly.
                }
                \only<2>{
                    Kerbl et al. bypassed this by decomposing $\Sigma$ into a scaling matrix $S$ and rotational matrix~$R$ mirroring standard eigendecomposition ($\Sigma=Q\Delta Q^{T}$):
                    $$ \darkmathhighlight{\Sigma = RSS^{T}R^{T} \hspace{2mm}\text{with}\hspace{2mm} \Delta = S^2, Q=R }$$
                }
                \only<3>{
                    The diagonal scaling matrix $S$ is further decomposed into three distinct scaling values $(s_{1}, s_{2}, s_{3})$. These represent the roots of the eigenvalues of $\Sigma$.
                }
                \only<4>{
                    The rotational matrix $R$ is decomposed into a four-value quaternion $(w, x, y, z)$:\\
                    \vspace{1em}
                    \resizebox{\linewidth}{!}{%
                    $ \darkmathhighlight{R = \begin{bmatrix}
                    1-2(y^{2}+z^{2}) & 2(xy-wz) & 2(xz+wy) \\
                    2(xy+wz) & 1-2(x^{2}+z^{2}) & 2(yz-wx) \\
                    2(xz-wy) & 2(yz+wx) & 1-2(x^{2}+y^{2})
                    \end{bmatrix}} $
                    }
                }
                \only<5>{
                    3DGS only stores and optimizes these 7 specific values for each 3D Gaussian.\\
                    \vspace{1em}
                    Because an eigendecomposition is always positive semi-definite, constructing a new covariance matrix from these components is guaranteed to be geometrically valid.
                }
            \end{overlayarea}
        \end{column}
